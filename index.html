          ABOUT THIS BUILD

          Honest prototype status

          The live next step updates locally using scanner report status and finding reviews. Choose local Ollama for an on-device next-step suggestion, or Groq cloud for evidence-linked analysis. With your consent, Groq receives the selected target, scope rules, question, scanner names with available reports, and up to 10 finding summaries with review statuses and short source excerpts. Analyst review notes, full report files, and API keys stay on this computer. If the selected provider fails, the page labels its rule-based fallback.

          • AI explanations are interpretations of scanner evidence; they do not confirm a vulnerability or start a scan.
          • ZAP runs a bounded crawl and passive response checks only; no active scan or exploit validation runs.
          • ZAP must be running locally with its API enabled and matching API key configured for the server.
          • A missing report means no results were recorded here; it does not mean the lab is safe.
          • Review priority starts from source severity; analyst context can raise it. Unknown or low source confidence is flagged.
          • Only scan or import results from your registered self-owned local lab or organizer-approved target.
          • Assessment records are stored in this browser. Copying the project folder does not transfer those records.
